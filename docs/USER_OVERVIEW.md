# 여백 · 사용자용 한 장

버전 **0.2.6** · 2026년 10월 25일

**이번 목표:** 말로 일정·할 일을 전달하고, 선택지로 필요한 정보만 확인한 뒤 승인해서 저장합니다.

## 새로 추가한 ‘대화로 등록’

1. Windows 실행 묶음을 실행하고 앱에 로그인합니다.
2. 왼쪽 **대화로 등록 → Continue with ChatGPT**를 누릅니다.
3. 본인의 ChatGPT 계정으로 로그인하고 구독 사용 권한을 확인합니다. 크레딧 사용을 허용하지 않도록 설정을 확인하세요.
4. **사용 가능한 모델 불러오기**를 누른 뒤 계정에 표시되는 모델을 선택합니다.
5. “이번 주말 친구와 저녁 먹기로 했어”처럼 대화로 전달합니다.
6. 각 질문의 선택지를 모두 고르고 **선택한 답변 한 번에 보내기**를 누릅니다. 선택은 전송 전까지 바꿀 수 있으며, 직접 추가 설명도 함께 보낼 수 있습니다. 모르는 정보는 미정으로 고릅니다.
7. 초안이 완성되면 **등록 전 확인** 창이 자동으로 열립니다. 핵심 내용을 확인하고 **확인한 내용 등록**을 누릅니다. 수정하려면 대화로 돌아갑니다.

날짜 없는 할 일, 여러 할 일의 개별 등록, 선택지 답변, 대화로 초안 수정, 승인·취소를 지원합니다.
저장 전에 질문이 남아 있으면 승인 버튼을 사용할 수 없습니다. 승인 전에는 받은함·캘린더에 추가하지 않습니다.

## 확인된 것과 아직 확인할 것

- 로그인·선택지·승인 저장의 코드를 추가했습니다. 서버 검사 75개, 브라우저 검사 11개와 빌드가 통과했습니다. AI 응답은 테스트에서 모의 처리했습니다.
- **실제 ChatGPT 로그인과 첫 AI 응답은 사용자 계정으로 확인해야 합니다.** 현재 클라우드에서 인증 서버 접근이 차단되어 실제 추론·계정 사용 가능 여부·사용량 차감은 미검증입니다.
- ChatGPT 구독 사용량과 앱별 한도가 적용됩니다. 추가 유료 API로 자동 전환하지 않습니다. 무료 무제한 사용을 보장하지 않습니다.
- 현재는 **새 일정·할 일 등록**을 위한 대화입니다. 기존 일정의 대화 조회·수정·삭제, 외부 예약, 푸시는 아직 지원하지 않습니다.

## 개발 AI에게 피드백 바로 보내기

1. **개선 기록 → 개발 AI에게 보내기 → Codex 로그인 창 열기**를 누르고 본인 ChatGPT 계정으로 로그인합니다. 일정 등록 AI 로그인과 별도입니다.
2. **로그인 상태 확인**을 누른 뒤 **최근 Codex 작업에서 환경 찾기**를 누릅니다. `vs014/personal_scheduler` 프로젝트의 환경을 선택합니다. 최근 작업에서 찾지 못하면 Codex 환경 설정의 **환경 이름 또는 ID**를 직접 입력합니다. 개발 브랜치는 기본값 `codex/feedback-delivery`를 사용합니다. **연결 설정 저장 → Codex 연결 확인**을 누릅니다.
3. 보낼 피드백을 선택하고 **선택한 피드백 보내기 전 확인**을 누릅니다. 확인창에서 내용과 환경을 확인한 뒤 전송합니다.
4. **전송 대기 → 접수 확인 → 검토 중/검토 완료** 상태와 **Codex 작업 열기** 링크로 결과를 확인합니다. 실제 접수 전에는 접수 완료로 표시하지 않습니다.

별도 Node 설치가 필요 없습니다. 작은 배포본(Light)은 첫 실행 때 공식 Codex 구성 요소 약 173MB를 내려받아 검증하고 이후 재사용합니다. 일반 배포본에는 구성 요소가 포함되어 있습니다. 첫 로그인 및 해당 계정의 클라우드 환경 접근 권한이 필요합니다. Codex 구독 사용량이 적용되며 유료 API로 자동 전환하지 않습니다.
새 클라우드 검토 작업을 만드는 기능입니다. 현재 Codex 대화에 추가되거나 앱이 자동 수정·설치되는 것은 아닙니다. 검토 결과는 작업 링크에서 봅니다.
전송 중 앱이 종료되면 ‘접수 확인 필요’로 남을 수 있습니다(최대 약 5분 후 판정). 중복을 막기 위해 자동 재전송하지 않습니다. Codex 작업 목록에서 생성 여부를 확인하고 해당 작업 링크를 연결하세요.
전송 전에 로그인·환경 확인에 실패한 경우만 안전하게 다시 보낼 수 있습니다. 환경을 바꿨다면 새 미리보기를 만드세요. 전송 기록은 기존 환경과 브랜치를 유지합니다.
실계정 클라우드 작업 생성과 Windows 실행은 아직 사용자 기기에서 확인해야 합니다. CLI는 실험적 기능이므로 연결 확인 결과를 확인해 주세요.

### 연결 확인에서 오류가 나면

0.2.6은 로그인 단계와 환경 접근 단계를 구분하고 오류 코드를 표시합니다. `[CODEX-ENV-NOT-FOUND]`는 이름/ID를 찾지 못한 경우, `[CODEX-NO-ENV]`는 해당 계정·작업공간에서 CLI가 환경을 찾지 못한 경우입니다. `[CODEX-403]`, `[CODEX-TLS]`, `[CODEX-TIMEOUT]`은 각각 접근 거부, 인증서, 시간 초과를 뜻합니다.
로그인 확인은 환경 이름을 입력하지 않아도 가능합니다. 환경 찾기는 최근 작업 최대 100개에 연결된 환경만 보여 주며 전체 환경 목록은 아닙니다. 작업 제목이나 내용은 화면에 표시하지 않습니다.
개발 환경 설정의 이름과 사용자 PC에서 로그인한 CLI가 접근하는 환경은 별도 확인이 필요합니다. 같은 계정이라는 사실만으로 동일한 작업공간과 환경 접근까지 보장하지는 않습니다. 오류가 나면 코드와 단계가 포함된 문구를 알려주세요. 토큰이나 로그인 주소는 보내지 마세요.

## 대화 응답 속도

선택지를 누를 때는 AI 요청이 발생하지 않습니다. 여러 답변을 묶어 보낼 때 한 번 요청합니다.
전송이 실패하면 선택과 추가 설명이 화면에 남아 다시 보낼 수 있습니다. 대화를 바꾸거나 새로고침하면 보내지 않은 선택은 초기화됩니다.
답변을 받은 뒤 소요 시간을 표시합니다. 모델은 **사용 가능한 모델 불러오기 → AI 모델**에서 변경할 수 있습니다.
현재 계정의 모델별 속도는 여기서 측정하지 못했으므로 자동으로 다른 모델을 고르지 않습니다. 실제 대기 시간은 모델과 네트워크 상황에 따라 달라집니다.

## 로그인 후 연결 오류가 나면

**대화로 등록 → 인증 서버 연결 확인**을 누르세요. 로그인 없이 공개 인증 서버 정보만 확인하며 일정·대화·인증 정보는 전송하지 않습니다.
오류에는 실패한 단계와 `[TLS-CERT]`, `[PROXY-CONNECT]`, `[DNS]`, `[TIMEOUT]`, `[HTTP-403]` 등의 코드가 표시됩니다. 그 문구를 개발 대화에 알려주세요. 비밀번호·로그인 주소·인증 코드는 보내지 마세요.
검사가 성공해도 실제 로그인이나 AI 응답 성공은 아닙니다. 이후 **Continue with ChatGPT**로 새로 연결하세요.
0.2.2는 로그인 정보 교환 중 `[TLS-CERT]` 오류에 대응하여 Windows 기본 인증서 검증 기능을 직접 사용합니다. 신뢰할 수 없는 인증서는 계속 차단합니다. 실제 노트북에서 로그인 재확인이 필요합니다. 같은 오류가 나면 괄호 안 인증서 코드를 포함한 문구를 알려주세요.

## 이번 피드백 반영

- 삭제·오늘 하기·완료·항목 수정 후 화면 아래 **되돌리기**로 직전 변경을 복원합니다. 다른 수정이 생겼으면 덮어쓰지 않습니다. 화면을 새로고침하면 버튼이 사라지며, 서버 복원 기록은 최대 24시간 유효합니다.
- 받은함을 구매·집안일·업무·건강·개인·기타로 묶습니다. 분류는 상세 화면에서 수정할 수 있습니다.
- 대화 등록 AI는 짧은 제목과 분류를 제안합니다. 기존 항목은 상세 화면의 **AI로 제목·분류 정리**를 누르세요. 해당 제목과 설명이 연결된 AI에 전송됩니다. 원문은 보존되며 확인 후 저장해야 반영됩니다. 날짜와 마감일은 바꾸지 않습니다.
- 피드백의 **현재 목록 전체 선택 / 전체 해제**를 지원합니다(한 번에 최대 100개).
- 전달 내용 확인창에서 **개발 AI에 보낼 내용 복사**를 누르면 파일 없이 Codex 대화에 붙여넣을 수 있습니다. 복사만으로 전송되지는 않습니다. 자동 전송은 아래 Codex 연결 기능을 이용합니다.
- 피드백 도움말과 일정 등록 AI의 연결 상태를 구분해 안내합니다.

## 계속 사용할 수 있는 것

직접 입력하는 받은함·오늘 할 일·캘린더·완료 기록, 질문·피드백 저장과 선택 전달, 두 종류 문서 열람.
‘질문·피드백’은 개발 개선 의견을 남기는 곳이고, ‘대화로 등록’은 일정·할 일을 등록하는 곳입니다.

## 개인정보와 업데이트

대화로 등록에는 해당 대화와 초안, AI로 정리에는 선택한 항목의 제목과 설명을 전송합니다. 기존 일정·피드백 전체를 자동 첨부하지 않습니다. Codex 전송에는 확인창에서 선택한 피드백 대화·처리 이력과 앱 버전만 포함합니다.
ChatGPT 연결은 앱 계정과 별도로 관리하고 연결 해제를 제공합니다. 데이터 폴더에는 이제 AI 인증 정보도 있으므로 파일을 타인에게 공유하지 마세요.

업데이트할 때 기존 실행 창을 닫고 새 ZIP을 다른 폴더에 풀어 실행하세요. Windows 사용자 데이터 폴더를 유지합니다.
사용자님은 원하는 기능·올바른 동작·우선순위를 결정하고, 개발 과정에서는 구현·검증·문서를 관리합니다.
